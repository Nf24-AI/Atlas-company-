# أطلس — مشروع الشركة الافتراضية

**النسخة الحالية: لعبة متصفح ثلاثية الأبعاد تعمل محليًا، مع Manager وDirector ومركز عمليات.**

## التجربة السريعة
- افتح `ATLAS-PLAYABLE-DEMO.html` مباشرة في المتصفح. هذه النسخة **تجريبية بلا ذكاء اصطناعي حقيقي**، وتخزن النتائج داخل المتصفح.
- أو افتح الطرفية داخل المجلد وشغّل `npm start` (Node.js 20+)، ثم اذهب إلى `http://127.0.0.1:3099`.
- اختبار الكود: `npm test`.

## ربط الذكاء الاصطناعي (محليًا فقط)
انسخ `.env.example` إلى `.env`، ثم أضف مفاتيح Groq وDeepSeek التي تخصك. مفاتيح API لا توضع في GitHub ولا في واجهة المتصفح. تأكد من أسماء النماذج المتاحة عند مزود الخدمة.

## ما الخطوة التالية؟
- اقرأ `PUBLISHING.md` لنشر المستودع عامًا وتشغيل **العرض التجريبي الثابت فقط** عبر GitHub Pages.
- اقرأ `CLAUDE.md` و `docs/WORK_ORDERS.md`.
- مهمة Claude الأولى: `COS-101` (تصادمات اللاعب وتحسين الكاميرا والاختبارات). يعمل في Branch منفصل ويسلم Pull Request للمراجعة.

**مهم:** المستودع العام ليس تطبيقًا سحابيًا آمنًا. لا تنشر خادم `server.js` للإنترنت؛ لأنه لا يدعم تسجيل الدخول أو فصل صلاحيات المستخدمين حتى الآن.
