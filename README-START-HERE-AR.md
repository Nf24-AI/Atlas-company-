# أطلس — الشركة الافتراضية

مكتب ثلاثي الأبعاد في المتصفح. أنت الرئيس التنفيذي، ومعك أربعة موظفين بالذكاء الاصطناعي: مدير المشاريع،
والمدير التقني، والمطوّر، ومهندس الجودة. يخططون للمشاريع ويناقشون القرارات، ثم يعدّلون الكود ويختبرونه داخل مستودع
معزول (sandbox)، ويطلبون موافقتك قبل أي دمج.

## التشغيل
- تحتاج Node.js بإصدار 22.13 أو أحدث. نفّذ `npm ci` ثم `npm start`، وافتح `http://127.0.0.1:3099`.
- في أول زيارة تنشئ حساب الرئيس التنفيذي، ويُحفظ على جهازك فقط.
- بدون مفاتيح API يعمل كل موظف في وضع **DEMO**: الردود مكتوبة مسبقًا ومعلَّمة بوضوح، والتكلفة صفر. أما تنفيذ
  الملفات والاختبارات وgit داخل الـsandbox فهو حقيقي.
- لتشغيل الذكاء الاصطناعي الحقيقي (**LIVE**، وله تكلفة)، ضع مفاتيح Groq وDeepSeek في ملف `.env`. هذا الملف لا يُرفع
  إلى GitHub أبدًا.

## أين أجد كل شيء؟
ابدأ من [docs/PROJECT-HUB.md](docs/PROJECT-HUB.md): الحالة، وخارطة الطريق، والأمان، والتكاليف، والاختبارات،
والتسليم.

**تنبيه خصوصية:** المستودع **عام** على GitHub، وكل ما يُرفع إليه يراه الجميع. لا ترفع مفاتيح أو بيانات شخصية،
ولا تنشر الخادم على الإنترنت.
